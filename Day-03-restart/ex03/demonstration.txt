Pour demontrer cet exercice il suffit d'aller dans le dossier install faire composer install, lancer la page php et regarder s'afficher 'hello'

Puis aller dans le dossier update, faire composer update, relancer la page php et voir les erreurs s'afficher et le hello disparaitre. Ensuite, remplacer la commande 'greet()' dans le fichier .php par 'hello()' pour que les erreurs disparaissent.
